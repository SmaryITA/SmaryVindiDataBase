# SmaryVindiDataBase

A complete database for Vindictus with all the necessary tables for:

- Raid
- Redeemer
- Space-Time
- Artifacts
- Scrolls
- Accessories
- Uaithne Gear + Tuning and Surplus
- Eriu Gear + Tuning and Surplus
- Advancement Stone

Works on Desktop and Mobile (Responsive)
